# Task 1 - Student Management API

## Project Description
A Student Management System developed using Python, Flask, SQLite and Streamlit.

The application provides CRUD operations to manage student records.

## Technologies Used
- Python
- Flask
- SQLite
- Streamlit
- REST API
- JSON

## API Features
- Add new students
- View all students
- Update student records
- Delete student records

## Streamlit Interface
The Streamlit dashboard allows users to:
- View students in a table
- Add new student records
- Select and update existing students
- Delete student records
- Refresh student data

## Database
SQLite is used to store student records.

## Testing
All CRUD operations were tested through the Streamlit interface.
